# Master Design Document (MDD)

This directory holds the compiled **Master Design Document** for this project.

Per the **Atomic Specs Governance Protocol § 4**:

1. Select relevant Spec Atoms from the portfolio.
2. Instantiate each atom (resolve all `{{...}}` placeholders with justified decisions).
3. Harmonize cross-cutting decisions (ADRs).
4. Freeze and version the MDD (v1.0 → source of truth for development).

## Files

| File | Purpose |
| --- | --- |
| `mdd-v1.0.md` | Initial Master Design Document (create this) |
| `adr-log.md` | Architecture Decision Records (optional separate log) |

> [!IMPORTANT]
> The MDD must be completed **before** implementation begins.
> All `{{...}}` placeholders represent Critical Decision Points requiring research.
